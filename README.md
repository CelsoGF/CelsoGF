## 🚀 Projeto

**GIRO – Pediu. Girou. Chegou.**
Plataforma de entregas que conecta lojas, clientes e motoboys. São 4 aplicativos web (PWA): Cliente, Lojista, Motoboy e Painel de gestão, com banco de dados no Supabase. Piloto planejado em Mar de Espanha (MG).
